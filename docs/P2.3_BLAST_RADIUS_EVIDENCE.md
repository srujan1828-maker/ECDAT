# ECDAT V4 P2.3 — Blast Radius Evidence & Provenance

## 1. Evidence Correlation & Relationship Binding
Every relationship in the persistent Crypto Asset Graph connects to underlying scanner evidence through `evidence_id`:
- **P1.1 Source Scanner**: AST call sites, import declarations, and cryptographic provider usage.
- **P1.2 Binary Scanner**: Dynamic import symbols, ELF DT_NEEDED entries, Mach-O load commands, and byte pattern signatures.
- **P1.3 Network Scanner**: TLS cipher suite negotiation, certificate chains, and HTTP endpoint binds.

During blast radius traversal, `correlate_path_evidence()` collects all evidence IDs from traversed edges, associating concrete proofs with every identified dependent.

---

## 2. Contradiction Detection & Inconclusive State
Graph edges may conflict with newly observed facts or removal markers:
- An edge indicates `app -> USES -> md5_hash`.
- A newer scan or code inspection records `evidence_state: CONTRADICTED` (e.g. `dependency_removed`, `unlinked`, `dead_code`).

When contradiction is detected:
1. `has_contradiction` becomes `True`.
2. The contradictory evidence is recorded in `contradicting_evidence`.
3. `confidence` transitions to `GraphConfidence.CONTRADICTED`.
4. `state` transitions to `BlastRadiusState.INCONCLUSIVE`.
5. `impact_category` transitions to `ImpactCategory.INCONCLUSIVE`.

---

## 3. Cryptographic Provenance Hashes
Every assessment computes three deterministic, tamper-evident SHA-256 hashes:

### 3.1 Canonical Graph Hash (`graph_hash`)
Computes a SHA-256 hash over canonical, sorted representations of traversed nodes and edges:
- Nodes: sorted by `(id, name)`.
- Edges: sorted by `(source, target, rel)`.
- Excludes timestamps, database autoincrement IDs, and memory pointers.

### 3.2 Evidence Hash (`evidence_hash`)
Computes a SHA-256 hash over sorted, deduplicated evidence IDs linked to the traversal.

### 3.3 Configuration Hash (`configuration_hash`)
Computes a SHA-256 hash over configuration parameters:
- `max_depth`, `max_paths`, `max_nodes`, `max_edges`, and context parameters.
