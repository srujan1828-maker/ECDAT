# ECDAT V4 — P2.1 Explainability & Audit Reason Chains
## Structured, Machine-Readable Decision Provenance

### 1. Explainability Requirement
A cybersecurity intelligence platform deployed in high-assurance environments cannot deliver black-box scores. Every risk assessment, PQC readiness state, and HNDL classification must produce a verifiable, deterministic **reason chain** connecting:
1. **Raw Observation**: What was detected (e.g., specific cipher suite in ServerHello, symbol in ELF table, dependency in manifest).
2. **Evidence Reference**: The P0 evidence ID, level ($E0$–$E5$), and state ($MEASURED$, $INFERRED$).
3. **Rule Reference**: The knowledge base rule ID (e.g., $LEG-001$, $PQ-KEX-001$) and triggered condition.
4. **Interpretation**: Why this finding matters mathematically and operationally.
5. **Actionable Remediation**: Recommended migration target (e.g., transition from RSA-2048 to ML-KEM-768).

```json
{
  "observation": "Deprecated/prohibited algorithm observed on asset-1.",
  "evidence_ref": {
    "evidence_id": "ev-net-001",
    "level": "E4",
    "state": "NEGOTIATED",
    "observation_type": "TLS_CIPHER_SUITE",
    "source_engine": "NETWORK"
  },
  "rule_ref": {
    "rule_id": "LEG-001",
    "rule_version": "1.0",
    "knowledge_base_version": "2024.1",
    "triggered_by": "algorithm_status=LEGACY, deprecation_status=DEPRECATED",
    "explanation": "Algorithm is deprecated or prohibited."
  },
  "interpretation": "Algorithm is deprecated or prohibited by NIST/BSI standards.",
  "result": "DEPRECATED_ALGORITHM"
}
```

---

### 3. Graph-Native Explainability API (`GET /api/assets/{asset_id}/why-risk`)

To allow human analysts and automated SOAR pipelines to query the exact rationale behind an asset's risk posture, ECDAT V4 provides `/api/assets/{asset_id}/why-risk`, returning:
- Asset metadata, type, and algorithm.
- Deterministic severity and confidence coordinates.
- Full `reason_chain` list.
- Multi-hop blast radius identifying all upstream applications, services, and libraries depending on this compromised primitive.
